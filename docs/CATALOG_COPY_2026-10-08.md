# 選択書籍の複写登録・空シリーズの整理（Ver1.2.9）

統合電子書庫で書籍をチェックし、「選択した書籍を複写登録」を開く。選択した巻の書名・著者・シリーズ・巻表示・並び順・版と、全所蔵先のprovider・形式・購入借用区分を下書きに引き継ぐ。新しい巻の情報へ編集し、「確認した複写を新規登録」で保存する。キャンセル・下書きを開くだけでは登録しない。複数巻も対象にでき、50巻ずつのページングでも入力を保持する。

各巻と所蔵には新しいIDを採番する。元の書籍・所蔵・進捗・履歴は変更しない。サービス内ID・URL・本体ファイル/Reader IDの紐付けは空欄、利用状態は未確認にする。手動進捗・読了・再読希望・借用期間・読書イベントはコピーしない。KUという購入借用区分は引き継ぐが、元の借用履歴は新しい巻へ接続しない。新しいID・URLは必要なら下書きで入力し、Localは登録後に本体を選択する。

確認した source book/holding のrevisionを保存直前に検証する。一件でも元データの変更・削除、重複サービスID、必須項目やURL等の不正があれば、単一トランザクション全体を拒否する。失敗時は下書きを残す。名前が同じでも自動統合はしない。

書籍の所属変更後、削除されていない巻が0冊のシリーズは同じ保存トランザクションで削除扱いにし、シリーズ一覧・選択肢から消す。残りの巻が一冊でもあれば残す。キャンセル・保存失敗では削除しない。過去の削除書籍の参照と今後の同期に備え、ID・削除時刻を保持する論理削除であり、書籍・所蔵・進捗・履歴は消さない。旧来の空シリーズも目録を開いた時の移行保存で整理する。JSON復元にも適用するため、空シリーズの不要な選択肢は復活させない。

`catalog-copy.js`は独立した下書き・保存候補を作り、`catalog-copy-editor.js`は注入されたDOM/翻訳/保存コールバックで編集する。`catalog-store.js`の書き込み時に`pruneUnusedCatalogSeries`を適用する。Nodeで複写の新ID・元データ維持・本体/履歴の非転用・競合・不正入力・空シリーズの冪等整理を確認。Chromeの実IndexedDB/DOMで複写のキャンセル/確定、複数所蔵の維持、履歴非転用、最後の巻の所属変更後のシリーズ消去を確認する。
