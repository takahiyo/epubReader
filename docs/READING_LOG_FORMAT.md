# 読書録のMarkdown形式

読書録のコピーとOS共有は、同じ「1記録＝1ノート」のMarkdownを出力します。作品と作者はObsidian形式の内部リンクで結び、進捗・日時は集計可能なプロパティとして保存します。

## 保存手順

1. 読書メニューの「読書録」を選び、コピーします。OS共有が使える端末では共有先かコピーを選択します。
2. Obsidianなどで新しいMarkdownノートを作り、**ノートの先頭**へ貼り付けます。既存ノートの本文途中へ追加すると、YAMLはそのノートのプロパティとして認識されません。
3. 例として `2026-10-04 作品名 123456.md` のように保存し、本文の「感想・メモ」へ自由に書き足します。作品・進捗などの記録はプロパティにのみ保存し、本文には重複させません。

同じ作品の記録は `book` と `book_id` で関連づけ、`recorded_at` で時系列に並べられます。作品・作者へのリンクを開くと、その作品や作者のノートを作成・参照できます。別のMarkdownツールでもYAMLをデータとして読み取れますが、`[[...]]` の内部リンク対応はツールによります。

## ファイル名からの作者・作品名の分離

`[作者名]作品_名_第003巻.epub` の場合、`authors`は`[[作者名]]`、`author_names`は`作者名`、`book`は`[[作品_名_第003巻]]`、`title`は`作品_名_第003巻`になります。対応形式の拡張子は除きます。作品名側の`_`と巻数はそのまま保持し、作品名と巻数の境界は推測しません。

先頭の角括弧が作者名として成立する場合は、読書録に限ってファイル名を優先します。保存済みの書籍情報は変更しません。古い書籍情報にファイル名がない場合は、同じ形式のタイトルから分離します。通常のファイル名・不完全な角括弧の場合は既存の作品名と作者情報を使用し、Web小説のタイトルはこの規則で分離しません。

### 作者と原作者の分離

`[漫画家×原作者]作品名.cbz` のように、角括弧内が`×`で2名に分かれる場合だけ、左側を作者（漫画家）、右側を原作者として推定します。`authors`・`author_names`には漫画家を、`original_authors`・`original_author_names`には原作者を保存します。英字の`x`は分割しません。空の名前や3名以上の表記も自動分離しません。

**注意：これはファイル名からの推定であり、役割が正しいことを保証するものではありません。誤っている場合は、コピー後のノートのプロパティを手修正してください。** 共有ウィンドウにも同じ注意を表示します。

## 表示言語とプロパティ名

日本語表示ではプロパティ名も日本語、英語表示では従来の英語キーで出力します。値（`reading`・`completed`など）、数値・日時・リストの型は言語に関係なく同じです。Obsidianがタグとして扱う予約名`tags`は、日本語でも変更しません。

既存ノートは変更しません。日本語名と英語名は別のプロパティとして扱われるため、集計やテンプレートで使用する場合は、記録時の言語を揃えるか、以下の対応表で読み替えてください。新形式の版は2です。

| 英語 | 日本語 |
| --- | --- |
| `type` | `記録種別` |
| `schema_version` | `形式版` |
| `date` | `記録日` |
| `recorded_at` | `記録日時` |
| `book` | `作品` |
| `title` | `作品名` |
| `authors` | `作者` |
| `author_names` | `作者名` |
| `original_authors` | `原作者` |
| `original_author_names` | `原作者名` |
| `status` | `読書状態` |
| `progress` | `進捗` |
| `book_id` | `書籍ID` |
| `format` | `書籍形式` |
| `page` | `ページ` |
| `total_pages` | `総ページ数` |
| `app` | `アプリ` |
| `app_url` | `アプリURL` |
| `tags` | `tags`（共通） |

以下の説明では、言語間の対応を明確にするため英語キーを使用します。

## プロパティの意味

| プロパティ | 型・意味 |
| --- | --- |
| `type`, `schema_version` | 記録種別と形式の版。UIの言語変更でも同じ値を使用 |
| `date`, `recorded_at` | コピー・共有時点の端末の暦日と、タイムゾーン付き日時 |
| `book`, `title` | 作品への内部リンクと元の作品名 |
| `authors`, `author_names` | 作者への内部リンクのリストと元の作者名のリスト。作者不明は空リスト |
| `original_authors`, `original_author_names` | 原作者への内部リンクと名前のリスト。該当しない場合は空リスト |
| `status` | `reading`（読書中）または`completed`（進捗が100%以上）。明示的な読了操作・読了日を記録するものではありません |
| `progress` | 0〜100の数値。表示単位は%。値に`%`を付けず、数値比較・並べ替えを可能にする |
| `tags` | `reading-log`タグで読書録を抽出 |
| `book_id` | 共通の同期書籍IDがある場合はそれを使用し、なければ端末内の書籍ID |
| `format` | EPUB、画像書庫、Web小説などの書籍種別 |
| `page`, `total_pages` | コピー時の表示ページ・総数。ページ分割中は暫定値になり、端末サイズや表示設定でも変わるため書籍の識別には使用しない |
| `app`, `app_url` | 記録元。URLの認証情報・クエリ・フラグメントを含めない |

プロパティの進捗とページ情報はコピー時の読書画面から取得します。本文断片・ローカルパス・任意の追加データは出力しません。

作品名・作者名にリンクやファイル名として使いにくい記号（`:`、`/`、`#`、`|`、角括弧など）がある場合、リンク先では全角に置き換えます。元の表記は`title`・`author_names`に保持します。既存のノート名が異なる場合は`book`・`authors`のリンク先を編集してください。ファイル名の`×`による2名の役割分離を除き、作者文字列を区切り文字から推測して分割しません。メタデータに複数作者の配列がある場合は個別のリンクを作ります。

評価やジャンルなどは、利用者が`rating`・`genres`等のプロパティを追加できます。既存の読書録を一括変換する処理はありません。

## 仕様の参照と検証

Obsidian公式の[Properties](https://obsidian.md/help/properties)・[Internal links](https://obsidian.md/help/links)を参照しています。YAMLプロパティはノート先頭に置き、内部リンクを引用符で囲みます。

自動テストでリンク・数値・日時・複数作者・特殊文字・進捗境界・許可外データの除外を確認します。ローカルでは独立したYAMLパーサーでも数値・リスト・日付・日時として読み取れることを確認しました。Chromeでは実際の読書録ボタンからのコピー、OS共有の模擬呼び出し、共有失敗時のコピーへの切替、横画面の共有選択とフォーカス移動を検証します。
