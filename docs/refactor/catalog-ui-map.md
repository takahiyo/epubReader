# 統合電子書庫の画面と操作（2026-10-08 / Ver1.2.9）

## 利用方法

左メニューの「統合電子書庫」、または読書メニューの「書籍 → 統合電子書庫」を開く。Ver1.2.8で、読書中は左メニューが隠れる問題に対応して書籍グループにも入口を追加した。フロートメニューを閉じて同じ目録画面を開き、登録・整理の実装や保存先は共通である。旧本棚のEPUB・画像書庫とクラウド目録を追加移行し、Kindle・U-NEXT・Localを手動登録できる。目録はこの端末内に保存する。読書状態の既存クラウド同期をONにしても、この目録はまだ他端末へ同期されない。

「書籍を登録」で新しい巻・版を作る。同じ巻を別サービスにも持っている場合、その巻の「所蔵先を追加」を使う。書名の一致では統合しない。シリーズは明示的な選択か新規作成で所属させる。巻表示は上・下・10.5・外伝等を文字列で保持し、並び順は整数で調整する。書名・シリーズの編集は同じ巻に属する全所蔵先に反映される。

Ver1.2.9で「選択した書籍をCSV出力」を追加。チェックした巻の全所蔵を、記入済みの追加登録用見本として保存できる。新規巻ではサービスID・URL・book_key等を見直し、取り込みのプレビューを確認する。既存情報の更新は行わない。空のCSVひな形も補助として残す。

同版で[複写登録と空シリーズの整理](../CATALOG_COPY_2026-10-08.md)を追加。チェックした巻・全所蔵先を新規登録の下書きにし、ID/URL/本体の紐付け/履歴をリセットして確認後に登録する。所属巻が0冊になったシリーズは保存時に論理削除し、一覧と選択肢から消す。

シリーズ・書名・著者・巻表示・版を検索でき、検索用文字列はNFKC・小文字へ正規化する。シリーズ・所蔵先・利用状態で絞り込む。結果は50巻ずつ表示し、同巻の複数所蔵を展開する。未知の巻を未購入と表示しない。CSVの追加登録・事前確認はVer1.2.6で実装し、[CSV操作仕様](../CATALOG_CSV_2026-10-08.md)に記載する。Ver1.2.7で[既存巻の一括整理](../CATALOG_BULK_2026-10-08.md)を追加し、ページ横断選択と各巻の手動ラベル・並び順を保存する。シリーズ別名編集と巻番号の推定候補は未実装。

## 読む導線

Kindle・U-NEXTは利用者が登録したHTTPSリンクを別タブで開く。URLなしでも所蔵登録できる。返却済み・利用終了のリンクは「再利用を確認」と表示する。外部サービスのログイン・借用可否・読書位置は公式環境で扱い、本アプリは自動取得・認証情報保存を行わない。

Localは旧Reader IDで既存の読み込み経路へ戻る。クラウド目録のみなら既存のファイル再選択導線を使う。本体未登録の手動所蔵ではファイル選択し、正常に開けたReader IDを所蔵へ結び付ける。既に別所蔵へ結び付いた本体を自動統合しない。競合時はファイルを開く処理と目録の保存結果を分け、目録でエラーを表示する。

## KU・手動状態

購入と読み放題借用は別所蔵。既存所蔵のサービス・購入借用区分は変更せず、必要なら追加所蔵を作る。同一provider・サービスID・購入借用区分の重複登録を拒否する。

「借用開始を記録」は新しい利用期間を作り、「返却を記録」は表示時に確認した期間IDを閉じる。返却で進捗・過去読了・読書イベントを消さない。再借用は別期間。手動状態・進捗・再読希望は利用状態から独立して保存する。イベントと現在状態、利用期間と所蔵状態はそれぞれ同じトランザクションで更新する。複数タブの古いrevisionからの操作は拒否する。

入力・借用・返却の日時は操作時刻。過去の日付を指定する編集、読了月検索、読書時間計測、統計は未実装。Local Readerの自動進捗は既存保存経路に維持し、目録の手動進捗とは別であることを画面に明記する。

## モジュールと検証

`catalog-actions.js` が登録・編集・借用返却・本体結合・検索索引を担当する。`catalog-ui.js` は翻訳・旧本棚取得・モーダル操作・Local読み込みを注入する。保存失敗を成功表示せず、入力を残す。タイトル等はDOMのtextContent、リンクは検証済みURLを利用する。通常編集は差分レコードだけを書き込み、JSON復元だけ全ストア置換する。復元は置換対象を明示した確認後に行う。

Nodeの目録操作テストとChromeの実IndexedDB・実DOMで検証。登録、同巻複数所蔵、全角半角検索、返却・再借用・再読後の読了保持、URL拒否、Local本体結合、再オープン、狭い縦横画面を確認する。10,000書籍・所蔵で表示DOMは50巻、検索反映はテスト端末のChromeで1ms（300ms以内の判定）。Android実機の性能・リンク遷移は未確認。

全体のbrowser-smokeには実アプリのメニューから目録を開き、EPUB/CBZのタイトルが移行される確認を追加する。既存リサイズテストは、前の共有画面試験と同じ1440×900への変更でresizeを待っていたため、異なる1280×900から開始して実際のイベントを検証する。
